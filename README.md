## 04 — System design lab

### Backend architecture

```mermaid
flowchart LR
    A["Client"] --> B["API / Router"]
    B --> C["Authentication & RBAC"]
    C --> D["Service Layer"]
    D --> E["Validation & Domain Rules"]
    E --> F["Repository Layer"]
    F --> G[("Database")]
    D --> H["External Services"]
```

### AI agent lifecycle

```mermaid
flowchart TD
    A["Request"] --> B["Context Retrieval"]
    B --> C["Agent / Model"]
    C --> D{"Tool Needed?"}
    D -- Yes --> E["Execute Tool"]
    E --> F["Validate Result"]
    F --> C
    D -- No --> G["Compose Response"]
    G --> H["Return Result"]
```
